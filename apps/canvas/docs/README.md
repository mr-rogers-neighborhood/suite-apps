# Canvas documentation

Canvas is a local-first, collaborative canvas. A workspace owns its cards; boards are views of those
cards. The document is a Loro CRDT, every write is validated in `@suite/graph`, and the canvas works
offline.

Canvas is alpha. `package.json` holds the current version and [CHANGELOG.md](../CHANGELOG.md) records
what each version changes.

## Two audiences

| Source | For |
| --- | --- |
| `docs/` (this tree) | Building, running, deploying and changing Canvas |
| `handbook/` | Using the interface: one article per element, menu, system and sub-system |

`docs/` stays developer documentation and never bleeds into the handbook; `handbook/` is the same
Markdown the app's own handbook shows, so an article written for a reader of the product is also the
article the app displays. Neither appears in the other's index.

Each section index lists its pages newest first and is generated by
`node scripts/generate-doc-indexes.mjs`; do not edit an index by hand.
