# How-to

One task at a time. These assume you know what you want to do.

| Page | Job |
| --- | --- |
| [Install, update and remove apps](install-update-and-remove.md) | Manage packs through the host, or install a frozen Flatpak |
| [Back up and restore a document](back-up-and-restore.md) | Keep a copy, or move a workspace to another machine |
| [Run the gate](run-the-gate.md) | Check a change before you commit |
| [Package and release](package-and-release.md) | Produce a host build, an app build, or a Flatpak |
| [Manage signing keys](keys.md) | Make, check, rotate and back up the pack and update keys |
| [Contribute a change](contribute.md) | From branch to merge, with the repo's rules |

App-specific jobs live in that app's `docs/how-to/`: for example, Canvas's
[import an Obsidian vault](../../legacy/canvas/docs/how-to/import-an-obsidian-vault.md).
