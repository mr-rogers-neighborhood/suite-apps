# How-to

One task at a time. These assume you know what you want to do.

| Page | Job |
| --- | --- |
| [Install, update and remove apps](install-update-and-remove.md) | Manage the apps through the hub |
| [Back up and restore a document](back-up-and-restore.md) | Keep a copy, or move a workspace to another machine |
| [Run the gate](run-the-gate.md) | Check a change before you commit |
| [Package and release](package-and-release.md) | Produce a hub build, an app build, or a Flatpak |
| [Contribute a change](contribute.md) | From branch to merge, with the repo's rules |

App-specific jobs live in that app's `docs/how-to/`: for example, Canvas's
[import an Obsidian vault](../../apps/canvas/docs/how-to/import-an-obsidian-vault.md) and
Suite Start's [install](../../apps/start/docs/how-to/install.md) page.
