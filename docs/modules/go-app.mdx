Suite Go is one Android app: the hub for the suite on a phone and the host for
the full applications that arrive as packs. Capacitor supplies the native
container, React 19 renders the shell, and Loro supplies the document CRDT. The
app is a container first. It owns the home surface, the frame a module renders
inside, the services a module may call, and the store that verifies what
arrives.

Two rules bound the module. The container carries a document's bytes and name
and never parses them; it routes on what a module declares and never branches on
a domain name. The pack store and the module contract are where those rules
become code. The Android project is generated by `cap add android` and
committed, because regenerating it loses the hand-edited share intent.

`pnpm check` is the local gate: Biome, typecheck and Vitest. Device behaviour is
checked by asking the running WebView through `pnpm android:eval`, not by
reading a screenshot.

## file: apps/go/scripts/pack.mjs

The builder and the device share one definition of the format. This script walks
the directory that will be installed, hashes each file, and imports
`canonicalManifestBytes` and `sha256Hex` from the contract package's built
output; the verifier in the app calls the same functions. A pack therefore
cannot claim a hash for content that was not in the directory, and a signature
made here verifies on a phone.

The private key is supplied through `--key` or `SUITE_PACK_KEY` and never lives
in the repository. A build with no key exits before writing an archive: a pack
that is not signed is not installable.
