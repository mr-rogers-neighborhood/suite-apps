## The mix we want

- A warm neutral canvas, one accent, and no rainbow chrome.
- Display type for the one thing that matters; 11–13px utility labels for everything else.
- Surfaces as layers: canvas → surface → sunk, one hairline, one shadow.
- Density changes room, never type.
- Motion quiet and short; content first, chrome recedes until needed.

## How to use them

- Name the reference and the property in a proposal: “Sunsama’s day-column rhythm”, not “make it
  Sunsama”.
- Add the pattern to the workbench with the real tokens and a story. Keep it
  `status:experimental` until axe is green and a screenshot exists, then tag it `status:ready`.
- When references conflict, the Suite rule wins: local-first, no account, no telemetry, data in a
  file the person owns.
