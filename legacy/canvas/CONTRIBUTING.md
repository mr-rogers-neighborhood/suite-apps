# Contributing to Canvas

The repository [CONTRIBUTING.md](../../CONTRIBUTING.md) owns setup, the gate, commits, review, docs
and the licence; [docs/how-to/contribute.md](../../docs/how-to/contribute.md) is the full guide.
Canvas's own rules for humans and agents are in [AGENTS.md](AGENTS.md), and `pnpm check` is the gate
a Canvas change runs against.
