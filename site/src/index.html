Work you keep in your own files.

Suite Desk runs signed packs on your computer. Suite Go runs the same packs on your phone. Every document a pack opens is a file you own: copy it, back it up, open it offline. There is no account, no telemetry and no server the project operates.

What Suite is

Documents, not accounts

A document is a file, handed to a pack as an opaque handle scoped to that pack. Nothing here has an account or a hosted copy.

Packs with a contract

A pack is a signed web bundle with a manifest. The host verifies the publisher key and every file hash before it runs, gives the pack its own origin and session, and enforces the capabilities the manifest declares.

Two hosts, one model

Canvas for boards, Planner for days, Budget for money: the same pack contract on the desktop and on a phone. A pack renders its UI; the host carries bytes and never parses a document.

The two hosts

Suite Desk

Alpha

The desktop host: one window, a tab per pack, a Home Screen and a local catalogue. It installs and updates from the signed Flatpak remote on Linux x86_64.

Suite Go

v0

The mobile host: one container, one pack at a time, and the same document boundary. It ships as an Android arm64 APK, not a Flatpak.

Install
